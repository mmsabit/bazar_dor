##Project Name: Bazar Dor

## Short Description
BazarDor is a platform where you can track the prices of your daily-use and grocery products.

## Technologies Used
- Next.js
- MongoDB
- Better Auth
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- BazarDor API

## Features
- Track product prices.
- Secure authentication.
- Category-wise products.
- Information about market prices in every area.
- Price-wise sorting.
